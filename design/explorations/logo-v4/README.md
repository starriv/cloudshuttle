# 云梭 Logo v4

云朵在上，两条小尺寸的对向直箭头放在云朵下方。箭头独立于云朵轮廓，上白下浅青，表达传输与返回。

- `preview.png` / `preview.svg`：静态应用图标预览。
- `logo.svg`：保留命名图层的完整矢量图，不含圆角裁切。
- `mark.svg`：透明背景单色标志。
- `design-sheet.png` / `.svg`：分层与小尺寸展示。
- `layers/`：云朵、向右箭头、向左箭头，各自独立的 SVG 和透明 PNG，统一 1024 × 1024 画布。
- `generate.py`：使用 CairoSVG 重新导出全部素材。

Icon Composer 中设置背景渐变（#25B9F2 → #087CEB → #1948BE），按编号导入独立 SVG 图层，保持同一画布坐标。源图层不含阴影、圆角蒙版或玻璃效果；在 Composer 中调整材质及检查系统外观。预览效果为静态示意。

本方案尚未替换应用当前图标，未生成 `.icon` 文件。
